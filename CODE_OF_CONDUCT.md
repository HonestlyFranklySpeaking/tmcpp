# Code of conduct

TMC++ is a small project made for fun and for learning. Keep it a friendly place to be.

- **Be kind and patient.** Many people here are students or new to Desmos, programming or open source.
- **Criticise code and ideas, not people.** "This breaks list instances" helps; "this is stupid" doesn't.
- **No harassment, insults or discrimination** of any kind, in issues, pull requests, discussions or anywhere else the project lives.
- **Assume good intent,** and ask before assuming the worst.

If someone breaks these rules, the maintainer may edit or delete their comments, close their issues or pull requests, or block them from the project. To report a problem privately, contact the maintainer, [@IkeaSourPatches](https://github.com/IkeaSourPatches), through GitHub.

These guidelines are inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
